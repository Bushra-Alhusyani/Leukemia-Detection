# 🩸 Leukemia Detection Using Hybrid Deep Learning

> A robust computer vision and deep learning framework designed for accurate leukemia detection from blood smear images, developed as a Capstone Graduation Project.

---

## 🌟 Overview

This repository showcases my core contributions to our team's graduation project: a hybrid deep learning framework engineered to classify leukemia blood cells using the **ALL-IDB2 dataset**. 

By combining the strengths of **EfficientNetV2-S** and **ConvNeXt-Tiny**, the proposed architecture extracts complementary visual features to significantly enhance classification performance and diagnostic reliability.

---

## ⚙️ Key Features & Pipeline

* **Data Preprocessing & Enhancement:** Advanced image handling, normalization, and contrast enhancement to optimize raw blood smear inputs.
* **Data Augmentation:** Robust transformations to prevent overfitting and improve generalization across diverse cell samples.
* **Hybrid Feature Extraction:** Leverages a dual-backbone architecture (**EfficientNetV2-S** & **ConvNeXt-Tiny**) for superior feature representation.
* **Rigorous Training & Validation:** Clean train/validation/test splits with optimized hyperparameters.
* **Comprehensive Evaluation:** Detailed metrics including **Accuracy, Precision, Recall, F1-Score, and Confusion Matrices**.
* **Visualizations & Artifacts:** Built-in plotting for training curves, loss metrics, and final model checkpointing.
